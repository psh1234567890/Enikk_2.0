# Enikk 2.0 · O(1) 알고리즘 동아리 디스코드 봇

기존 Enikk 2.0 코드를 정비한 버전입니다. Enikk 1.0은 별도 프로젝트로 보존합니다.

## 주요 명령
- !사용법
- !문법 vector/map/dfs
- !조회 [이름 또는 학번]: 실시간 백준/정올 티어를 조회, 오류면 DB 저장값과 구분
- !문제추천 [이름 또는 학번] / !추천: 상위 해결 문제 기준 난도로 미해결 5문제 추천
- !통계 [이름 또는 학번]: 백준 난도별 풀이 통계, 정올 확인 가능 범위 내 풀이 통계
- !전체목록: 이름 및 저장된 백준 티어
- !랭킹: DB에 저장된 백준 티어 기반 동아리 랭킹

## 환경 설정 및 개인정보 보호

1. .env.example을 .env로 복사하고 실제 키로 채웁니다.
2. DISCORD_TOKEN: 디스코드 봇 토큰
3. SUPABASE_URL: Supabase 프로젝트 URL
4. SUPABASE_KEY: Supabase anon/publishable 키. service_role 키 금지
5. O1_DB_ACCESS_KEY: Enikk용 읽기 접근 키 (관리자 C++의 키와 구분)
6. O1_GUILD_ID: O(1) 공식 디스코드 서버 ID (숫자 문자열)
7. O1_ALLOWED_CHANNEL_IDS: 학생정보 명령을 허용할 비공개 채널 ID를 쉼표로 구분

서버/채널 설정이 비어 있으면 !조회, !문제추천, !통계, !전체목록, !랭킹 명령은 자동으로 차단됩니다.
채널은 **동아리 관계자만 접근 가능한 비공개 채널**이어야 합니다.
!사용법, !문법은 학생정보를 사용하지 않습니다.

학생 조회 결과에는 이름과 공개 알고리즘 프로필 정보만 표시하고 나이·성별·학번은 표시하지 않습니다.
실제 데이터와 접근 키를 README, 로그, 저장소, 스크린샷에 복사하지 마세요.

## 빌드 및 테스트

Node.js와 npm 의존성을 설치한 뒤:

    npm ci
    npm run typecheck
    npm test
    npm start

개발 중에는 npm run dev로 빌드 후 실행합니다. .env를 바꿨다면 봇을 재시작하세요.
테스트는 외부 Discord/Supabase API에 연결하지 않습니다.
실제 봇 로그인과 live API 조회는 아직 별도 검증이 필요합니다.

## 구현 주의
- 정올은 HTML 구조가 변경되면 통계·티어 추출에 실패할 수 있습니다. 확인되지 않은 결과는 "확인 불가"로 표시합니다.
- 문제 추천은 통계적 중앙값이 아니라 최대 상위 11번째 해결 문제의 난도를 기준으로 합니다.
- Discord 명령은 동일 사용자의 연속 실행에 5초 간격을 적용합니다.
- 원본 Enikk 2.0 기능이 구현됐다는 사실과 학교 동아리에서 실제 배포·운영했다는 사실은 구분해야 합니다.
